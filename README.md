# Aniruddha Tiwari — DevOps Portfolio

A GitHub Pages-ready personal portfolio based on the provided design reference.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — PDF.js resume viewer
- `assets/resume.pdf` — uploaded resume

## Publish on GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to deploy.

## Before publishing

Replace the GitHub link in `index.html` with your actual GitHub profile URL.

The PDF viewer uses PDF.js from cdnjs, so the deployed site needs internet access for the viewer controls. The resume download/open links work directly from `assets/resume.pdf`.
